## 🔍 Overview

**IttihadBomber** is a Windows Forms application that generates **PowerShell downloader commands** for remote payload execution. It automates uploading files to Catbox.moe and creates one-liner PowerShell commands that download and execute payloads from the internet.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📁 **File Selection** | Browse and select any file (EXE, DLL, etc.) |
| ☁️ **Auto Upload** | Uploads files to Catbox.moe hosting service |
| 🔧 **Downloader Generation** | Creates PowerShell script to download and execute |
| 🔒 **Base64 Encoding** | Obfuscates PowerShell commands with Base64 |
| 👻 **Hidden Mode** | Runs PowerShell without showing a window |
| 📋 **Clipboard Copy** | Automatically copies the final command |
| 🎯 **One-Liner Command** | Generates single-line PowerShell commands |
